# HELIO HERITAGE FOODS

One-page bilingual website for HELIO HERITAGE FOODS.

## Technologies

- HTML
- CSS
- Vanilla JavaScript
- Static hosting with GitHub Pages Actions

## Local preview

Open `index.html` in a browser, or serve the repository root using any simple local static web server. No package installation or build step is currently required.

## Publish with GitHub Pages

The workflow in `.github/workflows/pages.yml` publishes the site from the root of the `main` branch. In repository Settings → Pages, set the source to **GitHub Actions**. A push to `main` or a manual workflow dispatch triggers deployment.

Do not merge unreviewed changes into `main`: production deployment is automatic on pushes to that branch.

Photo sources and license notes are in [`assets/IMAGE-CREDITS.md`](assets/IMAGE-CREDITS.md).
