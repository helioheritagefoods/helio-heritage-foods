# HELIO HERITAGE FOODS

One-page bilingual website for HELIO HERITAGE FOODS.

## Publish with GitHub Pages

The workflow in `.github/workflows/pages.yml` publishes the site from the root of the `main` branch. After pushing this repository to GitHub, set the repository's Pages source to **GitHub Actions**. Future pushes to `main` will deploy automatically.

The website is static and does not require a build step.

Photo sources and license notes are in [`assets/IMAGE-CREDITS.md`](assets/IMAGE-CREDITS.md).
